# Next.js Navigation Exam

A Next.js App Router project featuring navigation between Home, Profile, and Contact pages.

## Pages
- `/` — Home Page with `<Link>` buttons to `/profile` and `/contact`
- `/profile` — Profile Page displaying a profile picture using `<img>` and a Back button
- `/contact` — Contact Page displaying HCDC email with one-click copy and a Back button

## Setup & Run
```bash
npm install
npm run dev
```
Open [http://localhost:3000](http://localhost:3000) in your browser.
